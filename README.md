# TruckHub

TruckHub – LKW-Navigation mit Pausenplanung – Route, Lenkzeit 4,5 h, Pausen (15/30/45 min), Einsatzzeit, Fahrverbote, Live-Verkehr (TomTom), Parkplätze und Blitzer (AT).

Öffnen: https://airmax79.github.io/lkw-planer/

API-Keys werden nicht im Code gespeichert, sondern nur im Browser des jeweiligen Geräts.
